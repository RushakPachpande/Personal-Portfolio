# Rushak Pachpande Portfolio

Engineering case-study website for Rushak Pachpande — Platform Engineer.

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Framer Motion + React Router

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
